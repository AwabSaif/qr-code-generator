# QR Code Generator

A free, open-source, single-file web tool to create professional QR codes with Arabic UI support. Customize shape, card color, and caption text, then download a high-quality PNG or PDF.

Built by **Awab Saif**.

## Features

- Free to use — no signup, no watermarks
- Arabic (RTL) interface
- Visual shape picker (square, dots, rounded, extra-rounded, classy)
- Custom card background color and optional text under the QR
- HQ image download and PDF export
- Works as a Progressive Web App (installable)
- Single `index.html` file — open it anywhere

## Usage

1. Open `index.html` in a modern browser (Chrome, Firefox, Safari, Edge).
2. Enter a URL or any text in **QR content**.
3. Optionally add caption text under the code.
4. Pick a shape from the visual style grid.
5. Choose a card color.
6. Click **Generate**.
7. Download **HQ Image** or **PDF**.

### Install as an app (optional)

If your browser shows an install banner, click **Install** to pin the tool to your home screen / app launcher for faster access.

## Hosting

Upload `index.html` to any static host (GitHub Pages, Netlify, Cloudflare Pages, or your own server). No build step required.
